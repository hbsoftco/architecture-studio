# Known limitations

- The app is an early working implementation. Foundation and Mermaid phases 1–2 are complete; roadmap phases 3–10 are incomplete.
- BPMN step simulation supports start/end events, basic tasks, user/service tasks, and exclusive gateways with manual sequence-flow choice. It does not support parallel gateways, boundary events, timer semantics, subprocesses, or execution semantics. The DMN tester supports a narrow subset of decision tables with string, boolean, and numeric literals, simple numeric comparisons/ranges, and UNIQUE/FIRST/COLLECT policies; broader FEEL and DMN execution semantics are unsupported. XML validation checks basic structure, IDs, and references; full standards-aware validation remains pending.
- Visual graph editing supports property resize, single-node copy/paste, grid arrangement, zoom, pan, and independent flow/label directions. It still lacks resize handles, multi-selection, grouping, alignment tools, and diagram-specific constraints.
- Basic cross-document navigation, JSON Schema validation, and storage quota display are implemented. Element-level link editing, nested folders, and migrations are pending.
- Mermaid editor has line numbers, lightweight syntax coloring, live preview, zoom, and pan. It has no general purpose source formatter; Mermaid does not provide a lossless formatter for every diagram syntax.
- A sample BPMN visual edit survives XML round-trip, and a sample DMN document survives export/re-import. Vendor extension preservation and broader XML coverage remain unverified.
- BPMN Persian labels now use bundled Vazirmatn for measurement, display, direct editing, and offline SVG/PNG export in Chrome. Imported DI with inadequate element or label bounds can still cause collisions; the editor intentionally preserves that geometry. Other browser and external SVG rendering engines remain unverified. See `BPMN_RTL_RENDERING.md`.
- DMN edits may not trigger autosave in every editor view; export before leaving a complex edit session.
- Fullscreen uses the browser Fullscreen API when available and fills the viewport with a fixed workspace fallback when it is unavailable or rejected. DMN DRD views expose canvas zoom, fit, pan, and resize; decision table and expression views use their native scrolling and responsive layout because those editors do not expose a diagram canvas zoom or pan API. The floating properties panel can cover part of the canvas while open and may be collapsed from the toolbar.
- Offline PWA behavior has been verified for Mermaid import/export and images, sample ZIP import, BPMN/DMN XML exports, graph edit/restore, and BPMN SVG/PNG export. DMN image export and native visual edits offline remain pending.
- A representative four-document sample project and one production performance baseline are included. Large-diagram benchmarks, full security audit, and accessibility audit remain pending.
- The diagram catalog offers only registered adapters and existing Mermaid template variants. Its SVG examples are locally generated representative previews, not live editor instances. See `DIAGRAM_CREATION.md`.
