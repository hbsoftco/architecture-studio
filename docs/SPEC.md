# Product specification

Architecture Studio is a local-first diagram workspace for software engineers. The implemented release supports Persian and English UI, light and dark themes, local projects, Mermaid source preview, native BPMN/DMN editors, and a basic visual graph editor for architecture families. No BPMS runtime is provided.

The full target scope is recorded in the user brief; current coverage and gaps are tracked in `IMPLEMENTATION_PROGRESS.md`.
